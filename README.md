## 일하는 방식

프로젝트마다 AI와 일을 나누는 폭을 한 단계씩 넓혔습니다.

| 때 | 단계 | 한 일 |
|---|---|---|
| ~ 2025 | 직접 코딩 | 음악 SNS, 중고 악기 거래, 운영체제 스케줄러까지 손으로 짰습니다 |
| 2026.07 · PinLog | AI와 한 작업씩 | 규칙 문서를 두고 하나씩 지시하다가, 커밋 전에 보고받고 승인하는 절차를 거쳐 여럿을 동시에 돌렸습니다 |
| 2026.08 · FINCH | 역할을 나눔 | 작업을 지시하고 검토하는 대화와, 모르는 개념을 공부하는 대화를 따로 뒀습니다 |
| 2026.10 · 글로케어 | AI 팀을 운영 | 배분 · 감시 · 리뷰 세션과 기능 세션 최대 5개. 합치기 · 지우기 · 배포는 제가 허가해야 진행됩니다 |

AI가 쓴 코드는 그냥 믿지 않고 네 번 거릅니다.

1. 올리기 전에 체크리스트로 검사합니다. 실패했을 때의 처리와 범위 밖 값까지 봅니다.
2. 기능과 테스트 파일을 같은 MR에 올리고, 자동 검사(CI)를 통과해야 합칩니다.
3. 같이 관리자 화면을 만든 팀원이 스레드로 단 리뷰를 하나씩 고쳐 해결합니다.
4. 팀원 코드도 같은 기준으로 리뷰합니다. 문제 되는 줄을 발췌하고, 실행해서 확인한 것과 코드만 읽고 판단한 것을 나눠 적습니다.
